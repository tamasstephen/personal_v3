# My personal website

See: https://tamasstephen.com

## Design direction

The current experiment uses a readable product-landing-inspired portfolio
structure: short headline, useful profile summary, 1px rules, restrained
monochrome styling, a global scroll-triggered light/dark page theme, and
interaction only on clickable elements.

## Search and sharing

The canonical URL is https://tamasstephen.com/. The page includes ProfilePage
structured data with a Person entity and Open Graph / Twitter metadata.
The build includes `assets/social-preview.png`, a 1200 x 630 preview image.
To update the artwork, edit `assets/social-preview.html` and capture it at
1200 x 630 after its local fonts finish loading.
